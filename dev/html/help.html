📋 Credentials

The Credentials template is perfect for storing login information like usernames, passwords, and website addresses.

  • Table Format: Your information is organized in rows, with columns for website, username, and password
  • Click to Copy: Single-click any cell (like a password) to instantly copy it to your clipboard
  • Double-Click to Edit: Double-click any cell to make changes directly in the table
  • Add Rows: Click the "Add Row" button to add more login credentials
  • Delete Rows: Click the delete button (🗑️) next to any row to remove it
  • Filter/Search: Use the filter box to quickly find specific credentials

📝 Just Text

The Just Text template is a simple text area for storing any kind of unformatted text.

  • Perfect for: Notes, lists, ideas, codes, recipes, or any text you want to keep private
  • Simple: Just type or paste your text - no formatting, no complications
  • Large Capacity: Can store thousands of lines of text

🖼️ Images

The Images template allows you to store pictures securely in your vault.

  • Coming Soon: This feature is currently under development
  • Note: Adding images will make your vault file larger
  • Use Cases: Store important documents, ID scans, receipts, or personal photos

🚀 Getting Started

  1. Choose Content Type: Click the + button in the top-right to select what you want to store (Credentials, Just Text, or Image)
  2. Add Your Data: Fill in your sensitive information
  3. Enter Password: Type a strong master password in the center field (watch the strength bars!)
  4. Encrypt: Click the closed lock 🔒 icon
  5. Save File: Click the save icon 💾 in the top-left to download your encrypted vault
  6. Store Safely: Save the file to a secure location (USB drive, cloud backup, etc.)

🔓 Opening Your Vault Later

  1. Open the saved HTML file in your browser
  2. Enter your password in the center field
  3. Click the open lock 🔓 or press Enter to decrypt
  4. Make your changes
  5. Encrypt again with the closed lock 🔒
  6. Save to update the file (use Ctrl+S or click save icon)

✏️ Quick Tips

  • Edit Vault Name: Double-click the underlined title next to the save button, or click the pencil ✎ icon
  • Copy Credentials: Single-click any cell in the credentials table to copy it instantly
  • Edit Credentials: Double-click any cell to edit it directly
  • Show Password: Click and hold the 👁️ eye icon to reveal your password while typing
  • Keyboard Shortcut: Press Ctrl+S to save quickly

💡 Best Practices

  • Strong Passwords: Use 16+ characters with mixed types. Aim for gold (4 bars) on the strength indicator!
  • Multiple Backups: Keep copies in different secure locations (USB, cloud, external drive)
  • Multiple Vaults: Create separate vault files for different purposes (work, personal, etc.)
  • Regular Saves: Click save after making changes - there's no auto-save
  • Test Decryption: After encrypting for the first time, immediately decrypt to verify your password works

❓ Common Questions

Where is my data stored?

Only in the HTML file you save. There are no servers, no cloud, no databases. You have complete control.

Can I use this offline?

Yes! HTMLVault works completely offline. No internet connection required.

Is this really secure?

Yes! Uses AES-256-GCM encryption - the same standard as governments and militaries. With a strong password, it would take billions of years to crack.

Can I have multiple vaults?

Absolutely! Save different vault files for different purposes. Each can have its own password.

📖 Full User Guide (Step-by-Step for Beginners)

This guide explains everything in simple terms, perfect if you're new to encryption or not very tech-savvy.

What is This and How Does It Work?

Think of HTMLVault like a magic safety box for your secrets on your computer:

  1. You put things inside the blue box: You can write notes, save passwords, or add pictures in the blue area that says "Encrypted Area"
  2. You lock it with a secret word (password): When you type a password and click the lock icon, your information gets scrambled into a secret code that nobody can read
  3. You save it to your computer: The scrambled (encrypted) version gets saved as a file on your computer, just like saving a document
  4. You can open it again later: When you open the file and type your password, it unscrambles everything so you can see it again
  5. Nobody else can see it: Without your password, the file just looks like random gibberish - even the world's most powerful computers couldn't figure it out!

Important to understand: Your password is like the only key to your safety box. If you lose the key (forget the password), there is absolutely NO way to get your stuff back. So make sure you remember it or write it down somewhere safe!

Decide on a Content Template

Before you start, you need to choose what type of information you want to store. Here are your options:

  • Credentials: Choose this if you want to save login information (like passwords for websites, email accounts, etc.). It gives you a nice table where you can organize everything neatly.
  • Just Text: Choose this if you just want to write notes, lists, ideas, or any text. It's like a simple notepad.
  • Images: Choose this if you want to save pictures (this feature is coming soon!).

Don't worry! You can always change your mind later and create a new vault file with a different template. You can even have multiple vault files - one for passwords, one for notes, etc.

How to Use HTMLVault (Complete Step-by-Step)

STEP 1: Choose Your Content Type

  1. Look at the top-right corner of the screen
  2. Click the button with a plus sign (+)
  3. A menu will appear - click on "Credentials" if you want to save passwords, or "Just Text" if you want to save notes
  4. The blue area will now show either a table (for Credentials) or a text box (for Just Text)

STEP 2: Add Your Information

  • If you chose Credentials:
    • You'll see a table with columns for "Website", "Username", and "Password"
    • Click in any cell and type your information (like "facebook.com" under Website)
    • Click "Add Row" at the bottom if you need more rows for more passwords
  • If you chose Just Text:
    • You'll see a big text box
    • Just click inside and start typing your notes, lists, or whatever you want to save

STEP 3: Create a Password

  1. Look at the center of the top bar - you'll see a box that says "master password"
  2. Click in that box and type a password that you'll remember
  3. Make it strong! Use a mix of letters, numbers, and symbols. Watch the colored bars below - try to get them to turn gold!
  4. WRITE DOWN YOUR PASSWORD! Keep it somewhere safe like a notebook (not on your computer)

STEP 4: Lock (Encrypt) Your Information

  1. After typing your password, you can either:
    • Press the "Enter" key on your keyboard, OR
    • Click the closed lock icon (🔒) next to the password box
  2. The blue box will turn into scrambled gibberish - this is GOOD! It means your information is now encrypted and safe

STEP 5: Save the File to Your Computer

  1. Look at the top-left corner and click the save icon (💾) OR press Ctrl+S on your keyboard
  2. Your computer will ask where to save the file - choose a location you'll remember (like "Documents" or "Desktop")
  3. The file will be named something like "HTMLVault.html" - you can rename it to anything you want (like "My Passwords.html")
  4. Click "Save"

STEP 6: Opening Your Vault Later

  1. Find the saved HTML file on your computer (wherever you saved it)
  2. Double-click the file - it will open in your web browser (Chrome, Firefox, Edge, etc.)
  3. You'll see the scrambled gibberish in the blue box
  4. Type your password in the password box
  5. Press "Enter" or click the open lock icon (🔓)
  6. Like magic, your information will appear again!

STEP 7: Making Changes and Updating the File

  1. After opening your vault (decrypting it), you can make changes to your information
  2. Add new passwords, edit text, whatever you need
  3. When done, type your password again and click the closed lock (🔒) to encrypt it
  4. Click the save icon (💾) to save
  5. IMPORTANT: When saving, your computer will ask if you want to replace the old file - click "Yes" or "Replace". This updates your vault file with the new information. If you don't replace it, you'll have two files and might get confused about which one is the latest!

Renaming Your Vault File

You can change the name of your vault file anytime:

  • Before saving: When you click save, just type a new name in the file name box (like "Work Passwords.html" or "Secret Notes.html")
  • After saving: Find the file on your computer, right-click it, choose "Rename", and type a new name. Just make sure it still ends with ".html"!
  • Inside the vault: You can also double-click the title at the top (where it says "HTMLVault") to change what appears at the top of the page

Creating Multiple Vaults

You can have as many vault files as you want! For example:

  • One vault for work passwords (saved as "Work Passwords.html")
  • One vault for personal notes (saved as "Personal Notes.html")
  • One vault for important documents (saved as "Important Docs.html")

Each vault can have its own password and contain different information. Just save them with different names!
